# T774 — A DFO place cannot be saved as "not drawn, show DFO's words" (Kitimat west bank)

Status: OPEN (review app + marks model; related T754 one-bank places).

Source: second-look fix lane B follow-up, 2026-11-15 night (mark 2786).

## What is wrong
The Kitimat "west bank" place closes 750 m of one bank all year. Until T754 (one-bank places) is built the honest
state is "not drawn; the card says it in DFO's words". The mark model has no extent form for that: every saved place
must have an extent. Fallback used: mark 2786, tributaries off, still drawn full width (so the east bank reads closed
too, which is wrong toward closed).

## What to build
- A mark form "held, not drawn" with a reason; the place binds nothing, is named on the water's card with DFO's words,
  and is listed by the unplaced gate as accepted-by-owner (never silent).
- Or build T754 first, which removes the need for Kitimat. Decide which when T754 is scheduled.
