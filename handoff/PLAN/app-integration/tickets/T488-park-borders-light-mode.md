## Proposal (2026-11-08) — nothing applied

### Measured (park tokens over the light basemap's own grounds; ΔE2000, WCAG contrast)
The basemap already paints parks, woods and scrub GREEN (`landuse_park` #9cd3b4, wood #a0d9a0, scrub #99d2bb, landcover
#c4e7d2), and our park tint is a pale green over that, so it has almost nothing to show against.

| Light, current (fill #cfe3b4 @0.32, edge #5F8A3C @0.9, 0.8/1.5/2.0 px) | fill ΔE vs ground (worst CVD) | edge contrast vs ground |
|---|---|---|
| over land #e2dfda | 7.1 (2.5) | 2.67 |
| over wood #a0d9a0 (most of BC) | **2.5 (1.1)** | **2.24** |
| over park green #9cd3b4 | 3.3 (2.4) | 2.17 |
| over scrub #99d2bb | 3.9 (3.3) | 2.16 |

A ΔE under ~5 is "same colour" to the eye; the fill is invisible on every green ground and the edge is a 0.8-1.5 px,
2.2:1 hairline. Dark (fill #22371f @0.30, edge #4e7a44 @0.75): fill ΔE 7.0-8.0 (CVD 3.5-4.3), edge 2.5-2.6:1 — also
modest but it reads as a lighter-green box on near-black, and the owner did not report it: **dark left as is.**

### Option A — mid forest green (colour only, width unchanged, so the park edge stays finer than a closure edge)
Light and cvd themes (cvd's park tokens are the same today, change together):
```
color.park.fill       #cfe3b4 -> #3A7D44
opacity.park          0.32    -> 0.22
color.park.edge       #5F8A3C -> #3A7D44
opacity.park.edge     0.9     -> 1.0
width.park.edge       1.0     (unchanged)
```
Measured: fill ΔE vs ground 5.5-7.5 (CVD worst ~5), edge 3.1:1 on wood, 3.8:1 on land. Edge vs closed crimson under CVD
worst 12.5; vs open blue 7.2.

### Option B — deep pine (stronger; edge also 1.25x)
```
color.park.fill       #cfe3b4 -> #17604A
opacity.park          0.32    -> 0.20
color.park.edge       #5F8A3C -> #17604A
opacity.park.edge     0.9     -> 1.0
width.park.edge       1.0     -> 1.25   (1.0 / 1.9 / 2.5 px; z13+ is a touch wider than a closure edge, 1.2 / 2.0)
```
Measured: edge 4.6:1 on wood, 5.6:1 on land; vs closed crimson CVD worst 16.1, vs open 5.9. Clearly visible at z9-z13.
Caveat: the width ramp sits at/above the closure edge from z13, against the T311 "finer than a closure edge" rule —
if that rule stays, use B's colours at width 1.0 (not shot).

### Rejected
Olive/khaki (#6B5410 edge): reads on the ground, but is 2.5 from closed crimson under protan/deutan — fails hierarchy.
