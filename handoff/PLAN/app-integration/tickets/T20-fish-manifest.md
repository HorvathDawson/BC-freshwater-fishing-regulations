## Goal
Core knows, without importing assets, which species codes have a picture and their caption/credit; the mobile app knows how to
`require()` each picture. Both files are generated from `manifest.json` by one tool whose `--check` runs in `pnpm check`, like
`calendar.generated.ts`. Components receive the image map as a `FishImages` prop (ui-native may not import assets — `layers.json`:
only `apps/mobile` registers assets).

## Ports
- `FISHPIC(code)` = `images.filter(i => i.code === code)` → `FISH[code]` (same order; the FIRST image is the one every row shows:
  DV → "Bull trout", CT → "Coastal cutthroat trout").
- Entries with `code: null` are **skipped** (8 today: chum/coho/pink/sockeye × ocean/spawning, WDFW salmon) — they have no species row.
- Keys sorted by code for a stable diff; `JSON.stringify` for every string (captions contain no quotes today; never hand-escape).
- Caption suffix " ›" (U+00A0 + "›") is added by the presenter (T18 `CAPTION`), never baked into the generated file.
