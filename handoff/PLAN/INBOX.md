# Inbox: your notes for Claude to turn into tickets

Add anything here, in any form: UI bugs, ideas, data errors, questions. One line is enough. A screenshot path or a
water name helps. At the start of each session Claude reads this file and:

1. turns each note into a ticket (or adds it to an existing one) in `app-integration/tickets/` + the README ledger;
2. moves the note to **Filed** below with its ticket number, so you can see where it went;
3. asks you only when a note is unclear or needs a decision.
