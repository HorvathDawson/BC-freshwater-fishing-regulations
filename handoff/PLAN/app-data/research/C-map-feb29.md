FEB 29: both sides use the same leap calendar (calendar_spec.day_index; Mar 1 = 61 every year) → no off-by-one after Feb 28. Difference: page_v36.js clamps Feb 29 → Feb 28 (L31 TODAY, L1517 date box; DAYS has 365 entries; weekdayOf uses Feb 28's weekday); the app (statusIndex.ts L44–47) uses day 60. Today's data: 0 status profiles differ day 59 vs 60; no answers segment starts at 60 → identical status/answers. REAL divergence = weekday: 23 moment keys split by weekday across 59–60, e.g. zymoetz_river.r10 (Fri–Sun closure to non-guided non-resident aliens; Limonite Creek key 66): Feb 29 2036 is a Friday, the page answers with Thursday (no closure), Python tap gives the Friday closure; same in 2044, 2048. Latent: a segment starting at day 60 would never show on the page and be labelled "Mar 1".
Recommendation: one rule in calendar_spec (Feb 29 = day 60, real weekday, never clamped; ranges to Feb 28 already cover day 60 via range_days); emit worked cases [(iso, day, weekday)] to all three generated files; remove the page clamps; tests on TS, page harness, Python tap (Zymoetz 2036-02-29), and a data invariant (day 60 == day 59 everywhere).
